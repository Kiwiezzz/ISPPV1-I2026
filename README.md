## ISPPV1-I2026

This repository contains educational projects and study cases originally developed for the Video Game Programming I (ISPPV1) course at Universidad de Los Andes (ULA), Venezuela.

## Credits

All credit for the original study cases and course material goes to **Alejandro Mujica (R3mmurd)**. 

This project is built using **[Gale Engine](https://pypi.org/project/gale-engine/)**, a lightweight, modular Python game engine created by him on top of Pygame. 

## Getting Started with Gale

### Installation

To run these projects, you need to install the engine. You can do this easily via pip:

```bash
pip install gale-engine
